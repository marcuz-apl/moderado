# M6.2 Standalone Binaries Implementation Plan

**Goal:** Build unsigned Windows x64, macOS ARM64, and Linux x64 Moderado executables with checksums and an artifact manifest.

**Spec:** `docs/superpowers/specs/M6.2-standalone-binaries-design.md`

## Constraints

- Preserve `v0.2.21+260919v` for every M6 commit.
- Add `@yao-pkg/pkg` only as a development dependency.
- Do not publish, sign, notarize, or create a GitHub release.

## Task 1: Artifact metadata

Files: create `scripts/binaries.mjs`, `apps/cli/tests/binaries.test.ts`.

1. Write a failing test for `binaryTargets()` returning `moderado-win-x64.exe`, `moderado-macos-arm64`, and `moderado-linux-x64`.
2. Write a failing test for `writeArtifactManifest(directory, version, revision)` and `verifyArtifactManifest(directory, version)`, including a tampered-binary rejection.
3. Implement both functions using only `node:crypto`, `node:fs/promises`, and `node:path`. Each checksum file is `<sha256>  <filename>`. Manifest fields: version, revision, filename, platform, architecture, size, checksum, signed false.
4. Run `npm test -- apps/cli/tests/binaries.test.ts` and confirm it passes.

## Task 2: Binary builder

Files: modify `package.json`; modify `scripts/binaries.mjs`; modify `apps/cli/tests/binaries.test.ts`.

1. Write a failing test for `buildCommand(target, entry, output)`.
2. Add `@yao-pkg/pkg` to `devDependencies`.
3. Implement `npm run build:binaries`, which runs after the compiled CLI exists, invokes pkg once per configured target, then writes checksums and manifest under `artifacts/<VERSION>/`.
4. Implement `npm run verify:binaries`, which validates manifest/checksums and runs `--help` only for the host-compatible artifact.
5. Run the focused test and the host binary verification.

## Task 3: Release matrix

Files: modify `.github/workflows/release.yml`, `apps/cli/tests/release_workflow.test.ts`.

1. Add a failing test requiring a `binary-package` job, Windows/macOS/Ubuntu runners, `build:binaries`, `verify:binaries`, artifact upload, and no publishing token/command.
2. Add the read-only platform matrix. Every row runs npm CI, offline tests, its target build, host smoke test, and artifact upload.
3. Run the focused workflow test.

## Task 4: Documentation and closure

Files: modify `README.md`, `apps/cli/README.md`, `docs/RELEASING.md`, `docs/CLI_CAPABILITY_ROADMAP.md`, `HANDOFF.md`.

1. Document supported platforms, checksum verification, and the unsigned/artifact-only status.
2. Mark M6.2 complete after verification.
3. Run `npm test`, `npm run build`, `npm run verify:package`, `npm run verify:binaries`, and `git diff --check`.
4. Commit with `v0.2.21+260919v feat(release): add standalone binary artifacts` using hooks bypassed so the connected version remains unchanged.
