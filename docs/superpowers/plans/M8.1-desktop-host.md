# M8.1 Desktop Host Plan

1. Define versioned IPC schemas in `packages/contracts`.
2. Add offline tests for malformed messages, stale approvals, cancellation, and
   disconnect denial.
3. Add a minimal Tauri host prototype that starts and stops the agent process.
4. Verify that the CLI and future desktop host consume the same agent events.

M8.1 ends when the protocol is documented, validated offline, and reviewed;
visual chat UI belongs to M8.2.
