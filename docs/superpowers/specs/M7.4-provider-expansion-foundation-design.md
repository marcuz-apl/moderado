# M7.4 provider expansion foundation Design

**Milestone:** M7.4

## Goal

Make provider expansion reuse a shared OpenAI-compatible adapter while keeping the agent core provider-neutral.

## Architecture

The providers package exposes a configured OpenAI-compatible adapter layered on the existing HTTP behavior. CLI connections select it through provider contracts without importing provider details into core.

## Scope

Provider identity and base URL configuration, catalog discovery compatibility, model routing metadata, and provider-isolated tests. New proprietary provider protocols are excluded.

## Testing

Construct the adapter with alternate provider identity and base URL, then verify it preserves the common provider contract.

## Release notes

This document records the intended boundary and verification criteria for M7.4. It does not authorize external publication or relax Moderado's approval-first policy.
