# M7.6 real time web answers Design

**Milestone:** M7.6

## Goal

Answer weather, news, score, price, schedule, and traffic questions from live web evidence within a couple of seconds, without asking the user to fetch the data.

## Architecture

`web_search` resolves an ordered list of search sites: a configured custom endpoint first when one exists, then Exa (`https://mcp.exa.ai/mcp`, tool `web_search_exa`), then Parallel (`https://search.parallel.ai/mcp`, tool `web_search`). A hosted site is called with JSON-RPC `tools/call` and `Accept: application/json, text/event-stream`; the body is accepted as either direct JSON or SSE `data:` lines and validated with Zod before any text reaches the model. Failures and empty results fall through to the next site, and the last failure is reported as a bounded error result. Every attempt is aborted after 20 seconds by default, combined with the caller's abort signal so cancellation still wins.

The CLI detects current-information questions, executes the registered tool for five results, and appends the bounded evidence to the model task, so the answer needs a single inference round trip. Without a connected provider the bounded result is printed directly with its citations.

## Scope

Parameter schema changes (`endpoint` and `objective` optional), search-site selection, timeouts, payload validation, citation metadata, context bounding, question detection, prompt steering, and documentation. Model ranking, paid search accounts, and browser automation are excluded.

## Trade-offs

Hosted search services are contacted without credentials, which adds a third-party network destination; an operator can pin or replace the destination, and all search output remains untrusted reference data. The site order is static instead of measured per query, which keeps behaviour predictable and testable.

## Testing

Injected fetch implementations cover ordering, fallback, timeout, JSON and SSE parsing, citation extraction, and context bounding. Detection and task-building helpers are unit tested in the CLI suite. No automated test contacts a live search site.
