# M7.2 web aware answer evidence Design

**Milestone:** M7.2

## Goal

Preserve source attribution from approved search results so the terminal client can present evidence with an answer.

## Architecture

web_search emits normalized source metadata beside bounded text output. The agent event path retains the metadata without treating source text as policy.

## Scope

Source title, URL, snippet preservation; bounded context injection; clear unavailable or denied result handling. Search-provider selection UI is excluded.

## Testing

Use fake response payloads to assert source metadata survives success and absence/error paths without external network access.

## Release notes

This document records the intended boundary and verification criteria for M7.2. It does not authorize external publication or relax Moderado's approval-first policy.
