# M6.3 package manager manifests Design

**Milestone:** M6.3

## Goal

Generate reviewable package-manager manifests from verified binary release artifacts without publishing to any external channel.

## Architecture

A Node script reads the checked artifact manifest and checksums, then renders Homebrew, Scoop, winget, and AUR files. Generation is deterministic and remains separate from third-party repository submission.

## Scope

Homebrew formula, Scoop manifest, winget manifest, AUR PKGBUILD, checksum consumption, and offline tests. External publishing, signing, and artifact creation are excluded.

## Testing

Use temporary verified manifests to assert generated URLs, versions, architecture, and SHA-256 values; reject missing required platform artifacts.

## Release notes

This document records the intended boundary and verification criteria for M6.3. It does not authorize external publication or relax Moderado's approval-first policy.
