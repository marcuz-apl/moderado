# M7.1 approved web search Design

**Milestone:** M7.1

## Goal

Provide a bounded, approval-gated web search tool without giving models unrestricted shell or network access.

## Architecture

The tools package validates an HTTPS endpoint, query, result count, and response shape, then returns bounded search results and source metadata through the existing tool registry.

## Scope

web_search declaration, HTTPS validation, bounded native fetch, approval requirement, response normalization, and local fake-server tests. Browser automation and implicit network command execution are excluded.

## Testing

Use an in-process fake HTTP server for success, malformed response, HTTP rejection, and result bound tests; no external search service is contacted.

## Release notes

This document records the intended boundary and verification criteria for M7.1. It does not authorize external publication or relax Moderado's approval-first policy.
