# M6.4 release execution Design

**Milestone:** M6.4

## Goal

Define the maintainer-controlled publication process for an explicitly chosen public release.

## Architecture

The existing guarded GitHub workflow is the only publication entry point. It publishes verified npm and GitHub Release artifacts after explicit owner selection; generated package-manager manifests are submitted separately.

## Scope

Release version selection, release workflow inputs, artifact validation, npm trusted publishing, GitHub Release creation, and recorded signing status. Normal development commits and automatic package-manager submissions are excluded.

## Testing

Validate workflow structure offline and run package/binary verification before dispatch. The live publish is a manual owner action, not an automated test.

## Release notes

This document records the intended boundary and verification criteria for M6.4. It does not authorize external publication or relax Moderado's approval-first policy.
